🎴 RPG Card Designer

A small web application for creating and designing custom cards for tabletop RPGs.

The goal is to provide a simple and flexible editor for creating visually consistent cards for things such as abilities, spells, equipment, rules references, and other RPG content.

Goals
- Create custom RPG cards through a visual editor
- Support different card types and layouts
- Keep card content and visual design separate where possible
- Allow reusable card templates
- Provide a preview of the finished card
- Export cards for digital use or printing
- Keep the application lightweight and easy to use

Planned Technology

The project is intended to be implemented as a client-side web application.

Possible stack:

- React
- TypeScript
- Vite
- Local browser storage for persistence
- No backend required initially

The architecture and exact technology choices will be refined during development.

Project Status

🚧 Early planning / prototyping

The project is currently in its initial planning phase.
No functional application has been implemented yet.

Planned Features

Initial ideas include:

Card editor
Custom card dimensions
Text, images, icons and graphical elements
Reusable card templates
Configurable colors, typography and backgrounds
Live card preview
Save and load card designs
JSON import/export
Image or print export

The feature set may change as the project evolves.

# RPG Card Designer

A small client-side application for creating visually consistent, printable cards for tabletop RPGs.

This repository currently contains the React, TypeScript, and Vite technical skeleton. The card designer itself will be implemented incrementally.

## Get started

```bash
npm install
npm run dev
```

Create a production build with `npm run build`. Architecture and deployment details are in [`docs/initial-architecture.md`](docs/initial-architecture.md).
